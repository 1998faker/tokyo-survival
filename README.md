# 极恶东京生存之战 · 工程版

基于 2026-11-25 提供的单文件版。入口、脚本执行顺序和存档键沿用该版本。

## 启动

在本目录执行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:8000/`。使用 HTTP 可以让游戏的照片冲印功能读取同源图片的像素。部署时保留相对目录结构。

如果旧版是在另一个地址或通过本地文件打开的，先在旧版的设置或存档页导出存档，再在工程版导入。浏览器按站点区分本地存储。

## 编辑与构建

| 路径 | 内容 |
| --- | --- |
| `index.html` | 页面结构和加载顺序 |
| `source/engine/` | 共享检查、答题、生存、地图、剧情等源码片段 |
| `source/bundles.json` | 三个引擎脚本的拼接清单，数组顺序决定执行顺序 |
| `engine/shared.js`、`engine/core.js`、`engine/survival.js` | 生成的运行时脚本 |
| `engine/addons/` | 页面附加功能 |
| `data/` | 游戏配置和便利店美术索引 |
| `ui/` | 样式和一屏布局脚本 |
| `minigames/` | 柏青哥和水果小游戏入口 |
| `assets/` | 按所属代码分组的图片和音频，内容相同的资源共用文件 |

修改 `source/` 后，在本目录运行 `python3 build.py` 并刷新页面。生存引擎各片段共享原本的闭包，构建会将它们按清单拼回一个经典脚本。直接修改样式、配置或独立脚本后即可刷新。
